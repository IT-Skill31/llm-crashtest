# Security policy

## Reporting a vulnerability

Please **do not** open a public issue. Use GitHub's private vulnerability reporting
("Security" tab → "Report a vulnerability") on this repository.

Especially relevant: any way for an API key, token or other secret to end up in a
cassette file, or for a cassette name to write outside the cassette directory.

## Supported versions

Only the latest published minor version receives security fixes while the package is in 0.x.
